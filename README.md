# La Mesa del Duque

Sistema de gestión integral para restaurante desarrollado como proyecto académico de Gestión de la Calidad del Software.

## Estado del proyecto

El repositorio fue inicializado con este archivo base para habilitar la rama `main` y permitir que la estructura completa del sistema entre mediante Pull Request.

## Flujo de trabajo

- Todo cambio funcional debe realizarse en una rama separada.
- Todo cambio hacia `main` debe entrar mediante Pull Request.
- Las verificaciones de calidad, seguridad e integración se ejecutarán mediante GitHub Actions.
