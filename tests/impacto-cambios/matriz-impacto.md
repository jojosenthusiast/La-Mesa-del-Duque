# Matriz de Impacto — La Mesa del Duque

## Propósito

Este archivo complementa `docs/calidad/matriz-impacto-cambios.md` con el registro práctico de evaluaciones de impacto realizadas durante el desarrollo. Cada vez que se planifica un cambio en un componente, se evalúa su impacto y se registra aquí.

## Registro de evaluaciones de impacto

| Fecha      | Componente modificado | HU relacionada | Impacto identificado                     | Pruebas ejecutadas          | Resultado | Responsable |
|------------|-----------------------|----------------|------------------------------------------|-----------------------------|-----------|-------------|
|            |                       |                |                                          |                             |           |             |

## Cómo usar esta matriz

1. Antes de modificar un componente, consultar `docs/calidad/matriz-impacto-cambios.md` para identificar dependencias.
2. Registrar aquí el cambio planificado, los componentes impactados y las pruebas a ejecutar.
3. Después de la modificación, actualizar el registro con el resultado de las pruebas.
4. Si se descubre un impacto no previsto, actualizar la matriz principal en `docs/calidad/matriz-impacto-cambios.md`.
