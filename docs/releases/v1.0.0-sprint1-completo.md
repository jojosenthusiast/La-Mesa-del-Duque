# v1.0.0 — Sprint 1 Completo: Sistema operativo para restaurante

## Resumen ejecutivo

La versión 1.0.0 marca la entrega integrada del Sprint 1 de La Mesa del Duque. El sistema pasa de ser un prototipo parcial a una plataforma operativa completa para el personal de un restaurante, cubriendo las 8 historias de usuario comprometidas: registro y gestión de pedidos (POS), catálogo de productos, recetas, gestión de mesas, gestión de usuarios, autenticación con BCrypt, autorización por roles y notificaciones en tiempo real con SignalR.

Este release incluye backend completo (dominio, aplicación, persistencia), frontend operativo (4 módulos Razor Pages), infraestructura de calidad (207 tests, CI/CD, gobernanza) y documentación curada para cada versión.

### Módulos frontend

| Módulo | Rol operativo | Ruta |
|--------|--------------|------|
| Productos | Consola de mantenimiento | `/Operaciones/Productos` |
| Mesas | Superficie de control del salón | `/Operaciones/Mesas` |
| Pedidos | Terminal POS de servicio | `/Operaciones/Pedidos` |
| Usuarios | Administración de acceso | `/Admin/Usuarios` |

### Infraestructura técnica

- **Autenticación**: Cookies + BCrypt, timeout deslizante 8h
- **Autorización**: Claims de rol, `[Authorize]` por página
- **Notificaciones**: SignalR hub `/hubs/pedidos`, fire-and-forget
- **Base de datos**: PostgreSQL (Supabase) producción, SQLite tests
- **CI/CD**: GitHub Actions (build, test, regresión, CodeQL, Gitleaks, gobernanza)
- **Release**: Release Please + documentación curada
