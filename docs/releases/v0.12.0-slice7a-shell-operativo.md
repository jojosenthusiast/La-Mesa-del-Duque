# v0.12.0 — Slice 7a: Shell operativo, landing y auth guards

## Resumen ejecutivo

La línea 0.12.0 establece la **fundación visual y estructural** del frontend operativo para Sprint 1. Este slice reemplaza el layout scaffold por un shell de staff con navegación por módulos, convierte el landing en un hub operativo y agrega las guardas de autenticación que protegen todas las páginas de operaciones.

El shell sigue las 10 Reglas Doradas de Frontend Operativo definidas en el diseño del Sprint 1: registro de producto (no marketing), densidad media-alta, tipografía legible para uso repetitivo, y semántica de acciones y estados consistente para los tres módulos.

---

## Cambios principales

| Área | Cambio | Resultado |
|------|--------|-----------|
| Layout | Navbar operativa con tabs de módulos (Productos, Mesas, Pedidos) | El staff navega por módulo, no por página genérica |
| Landing | Hub operativo con tarjetas de acceso rápido | Punto de entrada claro a los tres flujos del Sprint 1 |
| CSS | ~280 líneas de componentes operacionales en `marca.css` | Shell, page headers, status badges, acciones semánticas, tabla ops, toasts, accessibility |
| Auth | `AuthorizeFolder("/Operaciones")` + AccesoDenegado | Todas las páginas operativas requieren autenticación |
| Tests | Shell smoke tests + IndexPage tests | Suite llega a 201 tests |

---

## Impacto funcional

- **Todo el staff**: ve una interfaz profesional de operaciones al ingresar, no un scaffold genérico.
- **Navegación**: tabs de módulos con estado activo visual permiten orientarse en un vistazo.
- **Seguridad**: las páginas operativas están protegidas — usuarios no autenticados son redirigidos al login.

---

## Impacto técnico

- Modificado `_Layout.cshtml`: navbar operativa, active tab via `ViewData["ActiveTab"]`, responsive con toggler
- Modificado `Index.cshtml` + `.cs`: `ModuleLinkVm` record, tarjetas por módulo
- Ampliado `marca.css` con sistema de componentes operacionales:
  - `lmd-ops-nav`, `lmd-module-tabs` (shell)
  - `lmd-page-header`, `lmd-page-subtitle` (headers)
  - `lmd-status-badge--active/busy/reserved/danger/neutral` (estados)
  - `lmd-action-primary/success/danger/neutral` (acciones)
  - `lmd-ops-table`, `lmd-money` (tabular numerals)
  - `lmd-toast-zone`, `lmd-sr-only`, `lmd-focus-ring`, `lmd-empty-state`
- Modificado `Program.cs`: `AccessDeniedPath`, `AuthorizeFolder`
- Creado `Pages/Auth/AccesoDenegado.cshtml`
