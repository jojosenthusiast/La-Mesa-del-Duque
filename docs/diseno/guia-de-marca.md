# Guía de marca

Lineamientos de identidad visual para La Mesa del Duque.

## Concepto

Identidad que transmite elegancia, confianza y profesionalismo. Inspirada en la realeza y la hospitalidad de alto nivel. Paleta cálida y sofisticada que genera cercanía y prestigio.

**Eslogan**: *El SaaS que gestiona tu restaurante como la realeza*

## Logotipos

### Variantes

| Variante | Archivo | Cuándo usarlo |
|----------|---------|---------------|
| **Principal** | `logo-principal.png` | Uso general: web, aplicaciones, documentos corporativos |
| **Color sólido** | `logo-solido.png` | Fondos oscuros o cuando se requiere alto contraste |
| **Monocromo** | `logo-monocromo.png` | Impresiones en blanco y negro o con color limitado |
| **Símbolo** | `logo-simbolo.png` | Favicon de app o navegación |
| **Icono** | `logo-icono.png` | Marca gráfica sola, sin texto |
| **Completo** | `logo-completo.png` | Presentación con logotipo y tipografía completa |

### Reglas de uso

- Mantener proporciones originales (no estirar)
- Zona de exclusión mínima: equivalente al alto de la "D" del logotipo
- Sobre fondos claros: usar variante principal
- Sobre fondos oscuros: usar variante de color sólido
- Tamaño mínimo en pantalla: 32px de alto para símbolo

## Tipografía

### Cinzel SemiBold — títulos

- Fuente serif con estilo clásico y elegante
- Peso: 600 (SemiBold)
- Uso: encabezados h1–h4, marca en navegación, elementos de identidad
- Carga: Google Fonts

### Montserrat Regular — cuerpo

- Fuente sans-serif moderna y legible
- Peso: 400 (Regular), 600 (SemiBold para énfasis)
- Uso: texto de cuerpo, botones, navegación, formularios
- Carga: Google Fonts

## Tono visual

- **Elegante pero accesible**: no excesivamente lujoso, sino profesional y cálido
- **Contraste alto**: accesibilidad como prioridad (WCAG AA mínimo)
- **Espaciado generoso**: respiro visual entre elementos
- **Sombras sutiles**: profundidad sin exageración
- **Transiciones suaves**: 200ms para interacciones
